# Kimia Farma Pharmacy Data Analysis

## 📊 Project Overview

This project analyzes Kimia Farma pharmacy data using **Power BI**.

The goal is to understand sales performance, product performance, branch performance, discounts, and inventory levels, and turn the data into useful business insights.

---

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Excel / CSV

---

## 📂 Dataset

The project includes four main datasets:

- `kf_final_transaction.csv` – Pharmacy transactions
- `kf_product.csv` – Product information
- `kf_kantor_cabang.csv` – Branch information
- `kf_inventory.csv` – Inventory and stock information

### Dataset Size

- **672K+ transactions**
- **150 products**
- **1,725 branches**
- **1M+ inventory records**
- Data period: **2020–2023**

---

## 📈 Analysis

The project covers:

- Revenue Analysis
- Transaction Analysis
- Monthly and Yearly Sales Trends
- Discount Analysis
- Product Analysis
- Product Category Analysis
- Branch Analysis
- Inventory Analysis

---

## 🔑 Key KPIs

Some of the main KPIs used in the dashboard:

- Total Revenue
- Total Transactions
- Average Transaction Value
- Revenue Contribution %
- Transactions Without Discount
- Discount Analysis
- Total Inventory Stock
- Zero-Stock Records

---

## 💡 Key Insights

- Revenue remained relatively stable from 2020 to 2023.
- February showed a recurring relatively lower revenue pattern.
- Discounts were used in most transactions.
- Revenue was more concentrated across certain product categories than across branches.
- Branch revenue was relatively evenly distributed.
- Inventory analysis provides an opportunity to identify potential stock-out and overstock risks.

---

## 📊 Power BI Dashboard

The final dashboard provides an interactive view of:

**Sales → Products → Branches → Inventory**

Users can explore the data using filters and visualizations to identify trends and business opportunities.

---

## 🎯 Business Objective

The main objective is to use data to support better decisions related to:

- Sales performance
- Product management
- Inventory planning
- Discount strategy
- Business performance monitoring
